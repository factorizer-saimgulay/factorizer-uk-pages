Analytics API (analytics)

HTTP endpoints of the analytics module under /api/v1/analytics: 47 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Analysis endpoints
  • Error codes
  • Events emitted
  • Related pages

The analytics module serves the analysis catalogue, fact profiles, descriptive statistics, statistical tests, classifications, saved models, reports, and summary refreshes over HTTP. All 47 endpoints sit under /api/v1/analytics. For business meaning see the Analytics module page.
