Auth API (auth)

/api/v1/auth altındaki auth modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 56 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Oturum açma ve oturum uç noktaları
  • Kullanıcılar uç noktaları
  • Roller uç noktaları
  • Yetkiler uç noktaları
  • ABAC ilkeleri uç noktaları
  • Onay zincirleri uç noktaları
  • Onay talepleri uç noktaları
  • Bildirim kuralları uç noktaları
  • Arayüz durumu uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

auth modülü oturum açmayı ve belirteç yenilemeyi, kullanıcıları, rolleri, yetkileri, ABAC ilkelerini, onay zincirlerini ve adımlarını, onay taleplerini, bildirim kurallarını ve kullanıcı başına arayüz durumunu sunar. 56 uç noktanın tamamı /api/v1/auth altındadır. İş anlamı için Auth modülü sayfasına bakın.
