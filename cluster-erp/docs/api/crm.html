CRM API (crm)

HTTP endpoints of the crm module under /api/v1/crm: 57 routes with permissions, schemas, status codes, and error codes.

The crm module serves customers, customer parts and their revisions, customer RFQs with lines, line materials and packages, and the CRM inbox. All 57 endpoints sit under /api/v1/crm. For business meaning see the CRM module page.
