CRM API (crm)

/api/v1/crm altındaki crm modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 57 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Müşteriler uç noktaları
  • Müşteri parçaları uç noktaları
  • Müşteri parçası revizyonları uç noktaları
  • Müşteri teklif talepleri uç noktaları
  • Teklif talebi kalemleri uç noktaları
  • Teklif talebi kalem malzemeleri uç noktaları
  • Gelen kutusu uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

crm modülü müşterileri, müşteri parçalarını ve revizyonlarını, kalemleri, kalem malzemeleri ve paketleriyle müşteri teklif taleplerini ve CRM gelen kutusunu sunar. 57 uç noktanın tamamı /api/v1/crm altındadır. İş anlamı için CRM modülü sayfasına bakın.
