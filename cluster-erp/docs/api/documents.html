Documents API (documents)

HTTP endpoints of the documents module under /api/v1/documents: 23 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Document types endpoints
  • Documents and versions endpoints
  • Error codes
  • Events emitted
  • Related pages

The documents module serves document types, documents linked to entities, document versions with file download, and the version approval lifecycle. All 23 endpoints sit under /api/v1/documents. For business meaning see the Documents module page.
