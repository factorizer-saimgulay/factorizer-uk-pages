Bu sayfa her başarısız API isteğinin döndürdüğü hata gövdesini anlatır ve kodda bulunan her hata kodunu listeler. src/cluster_erp/core/errors.py içindeki 213 kod sabitini, modüllerin ve sunucu dosyalarının yerel olarak tanımladığı kodları ve src/cluster_erp/server/error_handler.py içindeki istisna işleyicilerinin atadığı kodları kapsar. Hata modelinin tasarımı Hatalar ve istisnalar sayfasında anlatılır.

Hata gövdesi¶

Her işleyici gövdeyi _build_body ile kurar. src/cluster_erp/server/error_handler.py:33-46 içinden:

def _build_body(
    code: str,
    message: str,
    trace_id: str,
    details: dict[str, Any] | None = None,
) -> dict[str, Any]:
    body: dict[str, Any] = {
        "code": code,
        "message": message,
        "trace_id": trace_id,
    }
    if details:
        body["details"] = details
    return {"error": body}

_build_body ve RESOURCE_NOT_FOUND fabrikası not_found (src/cluster_erp/core/errors.py:357-367) üzerine kurulan örnekleyici yanıt:

{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "Warehouse (<warehouse_id>) not found",
    "trace_id": "<yymmdd>-<seq>",
    "details": {"resource": "Warehouse", "id": "<warehouse_id>"}
  }
}
Alan Anlam
code Makinece okunur kod. İstemciler onu yerelleştirilmiş bir iletiye eşler (src/cluster_erp/core/errors.py:6-16).
message Geliştiriciye yönelik İngilizce metin (src/cluster_erp/core/errors.py:10-11).
trace_id yymmdd tarih öneki ve trace_sequence tablosundan günlük sıra; tablo yazımı başarısız olursa zamana dayalı yedek (src/cluster_erp/server/error_handler.py:49-70).
details Yalnız boş değilse bulunur (src/cluster_erp/server/error_handler.py:45-46).
debug_message, exception_type İşlenmeyen ve eşlenen istisnalarda yalnız debug açıkken eklenir (src/cluster_erp/server/error_handler.py:306-308, src/cluster_erp/server/error_handler.py:346-347).

Not

Content-Length değeri max_request_body_bytes sınırını aşan bir istek, gövde okunmadan 413 ve REQUEST_TOO_LARGE koduyla reddedilir. Bu gövde code ve message taşır, trace_id taşımaz (src/cluster_erp/server/app.py:1396-1411).

Çekirdek hata modülünde tanımlı kodlar¶

src/cluster_erp/core/errors.py içindeki her yorum bölümü için bir tablo. Durum, atma konumu sayısı ve ilk konum; src/cluster_erp/ üzerinde AppError(...), core/errors.py fabrikaları ve HTTPException(...) için yapılan sözdizimi ağacı taramasından gelir. İleti sütunu ilk konumdaki İngilizce iletiyi alıntılar; kodun belirttiği nedendir. Atma konumu olmayan kod tanımlıdır ama taranan hiçbir çağrı onu atmaz. İstisna işleyicilerinin atadığı kodlar bunun yerine işleyiciyi gösterir.

Aynı dosyanın iş bölümlerindeki kodlar (CRM'den satın almaya) İş hata kodları sayfasında listelenir.
