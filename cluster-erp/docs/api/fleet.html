Fleet API (fleet)

HTTP endpoints of the fleet module under /api/v1/fleet: 116 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Assets and classes endpoints
  • Meters and readings endpoints
  • Maintenance endpoints
  • Fleet work orders endpoints
  • Operations endpoints
  • Fuel and compliance endpoints
  • TCO, tyres, and campaigns endpoints
  • Telematics endpoints
  • Error codes
  • Events emitted
  • Related pages

The fleet module serves fleet assets and classes, meters and readings, maintenance plans and reminders, fleet work orders, operations (assignments, couplings, inspections, defects, reservations, incidents), fuel and compliance, TCO, tyres, campaigns, emission factors, and a telematics feed. All 116 endpoints sit under /api/v1/fleet. For business meaning see the Fleet module page.
