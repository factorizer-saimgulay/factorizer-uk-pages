API

Fleet API (fleet)

/api/v1/fleet altındaki fleet modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 116 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Varlıklar ve sınıflar uç noktaları
  • Sayaçlar ve okumalar uç noktaları
  • Bakım uç noktaları
  • Filo iş emirleri uç noktaları
  • Operasyonlar uç noktaları
  • Yakıt ve uygunluk uç noktaları
  • TCO, lastikler ve kampanyalar uç noktaları
  • Telematik uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

fleet modülü filo varlıklarını ve sınıflarını, sayaçları ve okumaları, bakım planlarını ve hatırlatıcıları, filo iş emirlerini, operasyonları (atamalar, bağlamalar, muayeneler, kusurlar, rezervasyonlar, olaylar), yakıt ve uygunluğu, TCO'yu, lastikleri, kampanyaları, emisyon faktörlerini ve bir telematik beslemesini sunar. 116 uç noktanın tamamı /api/v1/fleet altındadır. İş anlamı için Fleet modülü sayfasına bakın.
