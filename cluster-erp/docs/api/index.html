API reference

Index of the Cluster ERP HTTP API reference: conventions, authentication, errors, system and shared routes, and one page per backend module.

Contents

  • Cross-cutting pages
  • Routes outside the modules
  • Module pages
  • Route count
  • Related pages

This section documents the HTTP API that the Cluster ERP server exposes under /api/v1, derived from the routers in src/cluster_erp/modules/*/ and src/cluster_erp/server/. It has four cross-cutting pages, two pages for routes outside the modules, and one page per backend module. Business meaning lives in the business modules section; this section covers paths, permissions, schemas, status codes, and error codes.

Cross-cutting pages¶

Page Type Scope
API overview explanation Base paths, module prefixes, OpenAPI availability, content types, and the path of one request
Authentication and headers reference Credentials, cookies, tenant selection, language, deactivation, and audit headers
API conventions reference Pagination, filtering, money, ids, soft delete, bulk operations, actions, and status codes
Errors reference Error body, exception handlers, and every error code
Business error codes reference Error codes of the business sections of the core error module

Routes outside the modules¶

Page Endpoints Scope
System endpoints 28 Health, readiness, security.txt, metadata, module list, display switches, signup, and the operator console
Shared server routes 40 Notes, attachments, e-mail, chat, composite party creation, party roles, and tenant fields

Route count¶

The server registers 1371 routes, counted from the source files:

Source Routes Counting method
src/cluster_erp/modules/** 1292 @<router>.get/post/put/patch/delete( decorators
src/cluster_erp/modules/subscriptions/customer_subscriptions/routes.py 4 router.add_api_route( calls
src/cluster_erp/server/routes/currencies.py 7 decorators; mounted by the currencies module
src/cluster_erp/server/routes/signup.py, src/cluster_erp/server/routes/vendor.py 21 decorators; mounted only when multi_tenant is on
other files in src/cluster_erp/server/routes/ 40 decorators
src/cluster_erp/server/app.py 7 @app.get( decorators; one exists only when multi_tenant is off

The 1360 route decorators named after a router (modules plus server/routes/) are the figure a plain grep returns. The module pages list 1303 routes in total.
