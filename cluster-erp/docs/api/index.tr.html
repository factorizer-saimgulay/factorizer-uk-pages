Bölüm

API başvurusu

Cluster ERP HTTP API başvurusunun dizini: kurallar, kimlik doğrulama, hatalar, sistem ve paylaşılan yollar ve arka uç modülü başına bir sayfa.

İçindekiler

  • Ortak sayfalar
  • Modüller dışındaki yollar
  • Modül sayfaları
  • Yol sayısı
  • İlgili sayfalar

Bu bölüm Cluster ERP sunucusunun /api/v1 altında sunduğu HTTP API'yi belgeler; içerik src/cluster_erp/modules/*/ ve src/cluster_erp/server/ içindeki yönlendiricilerden çıkarılmıştır. Bölümde dört ortak sayfa, modüller dışındaki yollar için iki sayfa ve arka uç modülü başına bir sayfa vardır. İş anlamı iş modülleri bölümündedir; bu bölüm yolları, yetkileri, şemaları, durum kodlarını ve hata kodlarını kapsar.

Ortak sayfalar¶

Sayfa Tür Kapsam
API'ye genel bakış açıklama Temel yollar, modül önekleri, OpenAPI erişilebilirliği, içerik türleri ve bir isteğin yolu
Kimlik doğrulama ve başlıklar başvuru Kimlik bilgileri, çerezler, kiracı seçimi, dil, kullanımdan kaldırma ve denetim başlıkları
API kuralları başvuru Sayfalama, filtreleme, para, kimlikler, geçici silme, toplu işlemler, eylemler ve durum kodları
Hatalar başvuru Hata gövdesi, istisna işleyicileri ve her hata kodu
İş hata kodları başvuru Çekirdek hata modülünün iş bölümlerindeki hata kodları
