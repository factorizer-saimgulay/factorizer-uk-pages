Intranet API (intranet)

HTTP endpoints of the intranet module under /api/v1/intranet: 117 routes with permissions, schemas, status codes, and error codes.

Contents

The intranet module serves content and spaces, audience segments, access grants, settings, comments, notifications, leave types, balances and requests, request types and requests, official deliveries, the directory, the caller's documents, kudos, quick links, alerts, events with media, and the feed. All 117 endpoints sit under /api/v1/intranet. For business meaning see the Intranet module page.
