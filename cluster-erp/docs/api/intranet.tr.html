Intranet API (intranet)

/api/v1/intranet altındaki intranet modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 117 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • İçerik, alanlar ve erişim uç noktaları
  • Bildirimler uç noktaları
  • İzin uç noktaları
  • Talepler uç noktaları
  • Resmi teslimler uç noktaları
  • Rehber uç noktaları
  • Belgelerim uç noktaları
  • Etkileşim uç noktaları
  • Etkinlikler ve medya uç noktaları
  • Akış uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

intranet modülü içerik ve alanları, hedef kitle segmentlerini, erişim izinlerini, ayarları, yorumları, bildirimleri, izin türlerini, bakiyelerini ve taleplerini, talep türlerini ve talepleri, resmi teslimleri, rehberi, çağıranın belgelerini, takdirleri, hızlı bağlantıları, uyarıları, medyalı etkinlikleri ve akışı sunar. 117 uç noktanın tamamı /api/v1/intranet altındadır. İş anlamı için Intranet modülü sayfasına bakın.
