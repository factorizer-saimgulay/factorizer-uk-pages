Inventory API (inventory)

HTTP endpoints of the inventory module under /api/v1/inventory: 51 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Warehouses and locations endpoints
  • Stock, movements, and reservations endpoints
  • Batches and serial numbers endpoints
  • Error codes
  • Events emitted
  • Related pages

The inventory module serves warehouses and storage locations, stock levels and availability, goods movements of every posting type, reservations, usage decisions, stock loans, batches, and serial numbers. All 51 endpoints sit under /api/v1/inventory. For business meaning see the Inventory module page.
