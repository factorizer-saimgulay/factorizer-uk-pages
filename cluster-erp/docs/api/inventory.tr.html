API

Inventory API (inventory)

/api/v1/inventory altındaki inventory modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 51 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Depolar ve yerler uç noktaları
  • Stok, hareketler ve rezervasyonlar uç noktaları
  • Partiler ve seri numaraları uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

inventory modülü depoları ve depolama yerlerini, stok seviyelerini ve kullanılabilirliği, her kayıt türündeki mal hareketlerini, rezervasyonları, kullanım kararlarını, stok ödünçlerini, partileri ve seri numaralarını sunar. 51 uç noktanın tamamı /api/v1/inventory altındadır. İş anlamı için Inventory modülü sayfasına bakın.
