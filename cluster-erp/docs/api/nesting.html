Nesting API (nesting)

HTTP endpoints of the nesting module under /api/v1/nesting: 27 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Nesting KPI endpoints
  • Nesting jobs endpoints
  • Nesting parts endpoints
  • Remnants endpoints
  • Error codes
  • Events emitted
  • Related pages

The nesting module serves nesting jobs with approval, costing, material reservation, export and result import, part pulls, summaries, and SVG and DXF output, plus nesting parts, remnants, and a KPI read. All 27 endpoints sit under /api/v1/nesting. For business meaning see the Nesting module page.
