Parties API (parties)

HTTP endpoints of the parties module under /api/v1/parties: 53 routes with permissions, schemas, status codes, and error codes.

Contents

  • Group facts
  • Endpoint summary
  • Countries and address levels endpoints

  • Communication channels endpoints
  • Person languages endpoints
  • Error codes
  • Events emitted

The parties module serves parties and their photos, addresses, communication channels and channel types, person languages, and the reference data for countries, address levels, and address level values. All 53 endpoints sit under /api/v1/parties. For business meaning see the Parties module page.
