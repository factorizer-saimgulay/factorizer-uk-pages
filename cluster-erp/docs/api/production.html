Production API (production)

HTTP endpoints of the production module under /api/v1/production: 102 routes with permissions, schemas, status codes, and error codes.

The production module serves work centres, operation types, routings and their operations, routing templates and cut technology rules, production versions, capacity reads, component allocations, production orders, work orders, and scheduling. All 102 endpoints sit under /api/v1/production. For business meaning see the Production module page.
