Production API (production)

/api/v1/production altındaki production modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 102 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • İş merkezleri uç noktaları
  • Operasyon türleri uç noktaları
  • Rotalar uç noktaları
  • Rota şablonları ve kesim kuralları uç noktaları
  • Üretim sürümleri uç noktaları
  • Kapasite uç noktaları
  • Bileşen tahsisleri uç noktaları
  • Üretim emirleri uç noktaları
  • İş emirleri uç noktaları
  • Çizelgeleme uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

production modülü iş merkezlerini, operasyon türlerini, rotaları ve operasyonlarını, rota şablonlarını ve kesim teknolojisi kurallarını, üretim sürümlerini, kapasite okumalarını, bileşen tahsislerini, üretim emirlerini, iş emirlerini ve çizelgelemeyi sunar. 102 uç noktanın tamamı /api/v1/production altındadır. İş anlamı için Production modülü sayfasına bakın.
