Projects API (projects)

HTTP endpoints of the projects module under /api/v1/projects: 64 routes with permissions, schemas, status codes, and error codes.

The projects module serves projects with production roll-up and earned value reads, schedules, kick-offs, meetings, actions, fixtures, project items, activities with relations and material links, and the project board. All 64 endpoints sit under /api/v1/projects. For business meaning see the Projects module page.
