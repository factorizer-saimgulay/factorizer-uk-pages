Projects API (projects)

/api/v1/projects altındaki projects modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 64 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Projeler uç noktaları
  • Çizelgeler uç noktaları
  • Başlangıç toplantıları uç noktaları
  • Toplantılar uç noktaları
  • Aksiyonlar uç noktaları
  • Fikstürler uç noktaları
  • Proje kalemleri uç noktaları
  • Faaliyetler uç noktaları
  • Proje panosu uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

projects modülü üretim özeti ve kazanılmış değer okumalarıyla projeleri, çizelgeleri, başlangıç toplantılarını, toplantıları, aksiyonları, fikstürleri, proje kalemlerini, ilişkiler ve malzeme bağlantılarıyla faaliyetleri ve proje panosunu sunar. 64 uç noktanın tamamı /api/v1/projects altındadır. İş anlamı için Projects modülü sayfasına bakın.
