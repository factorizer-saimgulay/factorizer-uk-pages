Sales orders API (sales_orders)

HTTP endpoints of the sales_orders module under /api/v1/sales_orders: 68 routes with permissions, schemas, status codes, and error codes.

The sales_orders module serves sales orders with PO checks, revisions, milestones, and status steps, order lines with BOM creation, units, shipments with lines, units, packages, and events, trade documents, and chain settings. All 68 endpoints sit under /api/v1/sales_orders. For business meaning see the Sales orders module page.
