Sales orders API (sales_orders)

/api/v1/sales_orders altındaki sales_orders modülünün HTTP uç noktaları: yetkiler, şemalar, durum kodları ve hata kodlarıyla 68 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Sevkiyatlar uç noktaları
  • Birimler uç noktaları
  • Ticari belgeler uç noktaları
  • Zincir ayarları uç noktaları
  • Satış siparişleri uç noktaları
  • Sipariş kalemleri uç noktaları
  • Hata kodları
  • Yayımlanan olaylar
  • İlgili sayfalar

sales_orders modülü sipariş kontrolleri, revizyonlar, kilometre taşları ve durum adımlarıyla satış siparişlerini, ürün ağacı oluşturmalı sipariş kalemlerini, birimleri, kalemler, birimler, paketler ve olaylarla sevkiyatları, ticari belgeleri ve zincir ayarlarını sunar. 68 uç noktanın tamamı /api/v1/sales_orders altındadır. İş anlamı için Sales orders modülü sayfasına bakın.
