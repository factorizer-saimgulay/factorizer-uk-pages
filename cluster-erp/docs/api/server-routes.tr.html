API

Paylaşılan sunucu yolları API

Modüllerin dışında src/cluster_erp/server/routes içinde tanımlı HTTP uç noktaları: notlar, ekler, e-posta, sohbet, taraflar ve kiracı alanları için 40 yol.

İçindekiler

  • Grup olguları
  • Uç nokta özeti
  • Notlar uç noktaları
  • Ekler uç noktaları
  • E-posta uç noktaları
  • Sohbet uç noktaları
  • Bileşik taraf oluşturma uç noktaları
  • Taraf rolleri uç noktaları
  • Kiracı alanları uç noktaları
  • Hata kodları
  • İlgili sayfalar

Bu sayfa src/cluster_erp/server/routes/ klasörünün tanımladığı ve create_app tarafından doğrudan eklenen 40 uç noktayı listeler (src/cluster_erp/server/app.py:1433-1440). Bunlar bir modülün parçası değildir; bu bağlamada require_app bağımlılığı eklenmez. Aynı klasörde currencies modülünün bağladığı currencies.py ile Sistem uç noktaları sayfasında belgelenen signup.py ve vendor.py de bulunur. Bu yolların arkasındaki mekanizma Paylaşılan sunucu yolları sayfasında anlatılır.
