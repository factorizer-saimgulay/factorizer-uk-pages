E2e suite catalogue

The 197 browser e2e suites of Cluster ERP in web-client/, grouped by functional area, with the shared helpers they use.

Contents

  • Scope and source
  • Suites by area
  • Shared helpers used by the suites
  • Constraints and validation
  • Related pages

This page lists every browser e2e suite in web-client/, grouped by the area of Cluster ERP it covers. It is a lookup table for finding the suite that guards a feature. How the suites run, and the rules they must follow, are on e2e battery.

Scope and source¶

  • Defined in: the files web-client/_e2e_*.mjs.
  • Count: 197 suites, counted with ls web-client/_e2e_*.mjs. The runner selects the same set (web-client/_run_battery.mjs:42-46).
  • Grouping: each suite was placed in one area from its file name and the first comment line of the file. A suite appears in one group only. The 15 group counts add up to 197.

Constraints and validation¶

  • Seven suites are self-hosted: they start their own server and databases. They are listed on e2e battery.
  • 195 suites call report from the shared base module to print their result line (counted with grep -l "report("). The other two print the line themselves; the runner accepts any line that matches N passed, M failed (web-client/_run_battery.mjs:97).
  • Every suite is checked by tests/test_e2e_db_isolation.py, which parametrises its tests over the same file pattern (tests/test_e2e_db_isolation.py:30).
