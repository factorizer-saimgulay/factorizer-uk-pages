Generic widgets

Reference of the metadata-driven desktop widgets in widgets/generic and the shared widgets in widgets/common, with field types, detail tab types, and formatters.

Contents

  • Scope and source
  • Screen classes

This reference lists the widgets that turn server metadata into desktop screens, in src/cluster_erp/desktop/widgets/generic/, and the shared building blocks in src/cluster_erp/desktop/widgets/common/. It gives the field types the field factory supports, the detail tab types, the cell formatters, and the toolbar signals. How a section chooses its screen is on tabs, panes, and layout. The metadata classes themselves are on metadata model.

Scope and source¶

  • Defined in: src/cluster_erp/desktop/widgets/generic/*.py (17 files) and src/cluster_erp/desktop/widgets/common/*.py (11 files), counted without __init__.py.
  • Count: 19 public classes in generic/ and 11 public classes in common/, counted as class statements whose name starts with a capital letter. Field types were counted from the branches of create_field (src/cluster_erp/desktop/widgets/generic/field_factory.py:419-480). Detail tab types were counted from GenericDetailView._setup_ui (src/cluster_erp/desktop/widgets/generic/generic_detail_view.py:148-189).

The table has 14 rows for 17 field_type values, because four JSON-like values share one row. A field with semantic set to password hides its input (src/cluster_erp/desktop/widgets/generic/field_factory.py:476-478). Numeric controls ignore the mouse wheel until they have focus (src/cluster_erp/desktop/widgets/generic/field_factory.py:41-45).

DecimalLineEdit validates input with a regular expression built from max_digits, decimal_places, and allow_negative and never converts to float. Its docstring cites the Decimal-only money standard (src/cluster_erp/desktop/widgets/generic/field_factory.py:148-182). See money and decimal. tests/test_desktop_datetime_field.py pins the datetime round trip (tests/test_desktop_datetime_field.py:45-71).

Constraints and validation¶

  • GenericFormDialog._on_save runs GenericForm.validate and shows the first error as a toast before it sends anything (src/cluster_erp/desktop/widgets/generic/generic_form_dialog.py:209-215).
  • Toolbar buttons follow the user's permissions: create needs <entity>.create, delete needs <entity>.delete or <entity>.bulk_delete, and save needs <entity>.update (src/cluster_erp/desktop/widgets/generic/generic_list_view.py:103-107, src/cluster_erp/desktop/widgets/generic/generic_detail_view.py:513-515). The server enforces the same permissions; see roles and permissions.
  • tests/test_desktop_table_text_insets.py pins header and cell text positions on the real stylesheet (tests/test_desktop_table_text_insets.py:104-135).

Discrepancies¶

Warning

Discrepancy. The project's written engineering rules list the common widgets as ListView, TreeView, DetailForm, ConfirmDialog, and Toast. In src/cluster_erp/desktop/widgets/common/, the tree widget is TreePanel (src/cluster_erp/desktop/widgets/common/tree_view.py:23) and detail_form.py holds FormToolbar (src/cluster_erp/desktop/widgets/common/detail_form.py:10). No class named TreeView or DetailForm exists there. This page documents the code.

Warning: Discrepancy. The project's written engineering rules describe the list standard as selection by press-and-hold, actions in a card from the bottom, and a labelled actions entry. GenericListView selects rows with check boxes, places metadata action buttons in a bar above the list, and offers bulk delete in its toolbar (src/cluster_erp/desktop/widgets/generic/generic_list_view.py:110-137, src/cluster_erp/desktop/widgets/common/list_view.py:222-223, src/cluster_erp/desktop/widgets/generic/generic_list_view.py:542-561). This page documents the code.
