This wiki documents Cluster ERP as the code implements it. It is the entry point for users, administrators, developers, and operators, and it links to every section. It does not repeat the content of the sections; each section index lists its own pages.

What Cluster ERP is¶

Cluster ERP is a modular enterprise resource planning system. The server is a FastAPI application built by create_app (src/cluster_erp/server/app.py:1287-1296) that stores its data in PostgreSQL through the asyncpg driver (src/cluster_erp/config/settings.py:841). Its business logic lives in 28 backend modules, counted as the 28 classes that subclass ModuleBase in src/cluster_erp/modules/*/module.py. The project's written engineering rules require modules to talk to each other only through the EventBus. Users work in a metadata-driven web app in webapp/, which the server serves at /app (src/cluster_erp/server/app.py:1633-1644), or in a PySide6 desktop client in src/cluster_erp/desktop/ (src/cluster_erp/desktop/main.py:139). Both clients build their screens from the metadata document that the server publishes at /api/v1/_meta (src/cluster_erp/server/app.py:1518, src/cluster_erp/desktop/core/metadata_store.py:13), and both call the same HTTP API.

How to read this wiki¶

Each page has one type: a tutorial teaches by doing, a how-to guide completes one task, a reference page lists facts, an explanation describes how and why a part works, a module page gives an overview of one backend module, an API page lists the endpoints of one router group, and an index page lists the pages of a section. Every statement about behaviour cites the code that shows it, as a path and line range such as src/cluster_erp/core/module_base.py:62. The text "Not determined from code." marks a question that the code does not answer. A warning that starts with "Discrepancy." records a place where the code and the project's written engineering rules differ; it describes both sides and decides nothing. Every English page name.md has a Turkish twin name.tr.md in the same folder with the same structure, and the language switch moves between them. The last line of each page names the commit and the date that the page was checked against.
