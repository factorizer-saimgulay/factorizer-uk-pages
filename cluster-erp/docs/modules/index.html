Business modules

Landing page of the modules section, with one row per backend module, its own one-line description, and a link to its page.

Contents

  • Module list
  • Folders with several pages
  • Related pages

This section has one page or one folder per backend module in src/cluster_erp/modules/. The table lists all 28 modules, counted as the folders whose module.py defines a class that subclasses ModuleBase. The purpose column quotes the description property of each module class, so it says what the module says about itself. How modules are loaded and how they talk to each other is explained in module lifecycle and event bus.

Folders with several pages¶

Ten modules have a folder because their scope is split across several pages: analytics, crm, fleet, intranet, nesting, parties, procurement, production, projects, and sales_orders each open on their folder's index.md. In this group, the parties folder also holds party unification, the sub-module references, and settings and reference data. The nesting folder holds the engine, jobs, parts, and remnants, and integration and KPI.
