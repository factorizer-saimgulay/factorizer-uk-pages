This page lists the top-level folders and files of the Cluster ERP repository and says what each holds. It is a lookup table for finding code. It does not explain how the parts work together; see the architecture overview for that.

Scope and source¶

The lists were produced by listing the repository root and each named folder at commit 7793ff4. Counts state their method in the table.

  • Defined in: the repository tree
  • Count: 15 source folder rows, 1 CI folder, 5 runtime or personal folders, and 11 root file rows

Constraints and validation¶

  • The Alembic folder is migrations/ (alembic.ini:2). migrations/env.py imports every module's models package to build the target metadata (migrations/env.py:76-86).
  • The server finds the web app at <repository root>/webapp (src/cluster_erp/server/app.py:1633). It mounts it only when the folder exists (src/cluster_erp/server/app.py:1634).
  • Whether the Vite React project in web-client/src is in use is not determined from code. web-client/README.md is the stock Vite template text.
