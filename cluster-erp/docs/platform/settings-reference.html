This page lists every field of Settings in src/cluster_erp/config/settings.py, the validation rules that run when settings load, and the derived properties. It is a lookup table for developers and operators. Which variables a Linux node sets, and how, is in the configuration reference.

Scope and source¶

  • Defined in: src/cluster_erp/config/settings.py (Settings)
  • Count: 183 fields, counted as the annotated class attributes between the class Settings line and the validator (src/cluster_erp/config/settings.py:64-738). The four annotated lines of the RegionAddress dataclass above it are not settings.

Settings is a Pydantic BaseSettings class. It reads environment variables with the prefix CLUSTER_ERP_, case-insensitively, and also reads a .env file in the working directory (src/cluster_erp/config/settings.py:64-70). The environment variable of a field is CLUSTER_ERP_ followed by the field name in upper case.

The columns are:

  • Default: the default in code. Values that are or could be secrets, host names, addresses, or paths on a node are shown as <value>, following the security disclosure policy of the documentation standard. Long lists say "see source".
  • Read in: the folders or modules whose code reads the field as settings.<name> or with getattr(settings, "<name>"), found with grep over src/cluster_erp. config means the field is read only inside settings.py itself, by a derived property. - means no reader was found by that method.
  • Meaning: one sentence from the comment above the field. "No description in code." means there is no comment.

Constraints and validation¶

The validator _validate_settings runs after the fields load (src/cluster_erp/config/settings.py:739-836). Loading fails with a ValueError when:

  • A region code is not 2 to 8 characters of lower-case letters, digits, or hyphens; region_db_urls names an unknown region; or a non-default region has no server (src/cluster_erp/config/settings.py:746-753).
  • node_country is set and is not a two-letter code, or country_nodes does not list this node's own country (src/cluster_erp/config/settings.py:754-765).
  • multi_tenant and debug are both on (src/cluster_erp/config/settings.py:766-770).
  • secret_key keeps its shipped default outside debug mode, is shorter than 32 characters, or is weak outside debug mode. In debug mode a default key is replaced by a generated one and a weak key only logs a warning (src/cluster_erp/config/settings.py:771-804).
  • In multi-tenant mode, storage_encryption_key, backup_encryption_key, or mail_encryption_key is empty (src/cluster_erp/config/settings.py:805-821).
  • storage_encryption_key or backup_encryption_key is set but is not 32 bytes of hex (src/cluster_erp/config/settings.py:822-827).
  • storage_backend is s3 and s3_bucket is empty (src/cluster_erp/config/settings.py:828-831).
  • smtp_host is set and smtp_from_email is empty (src/cluster_erp/config/settings.py:832-835).
