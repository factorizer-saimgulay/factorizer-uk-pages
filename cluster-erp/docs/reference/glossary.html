This is the one glossary of the Cluster ERP wiki. It collects every term that a wiki page introduces, with the code identifier, a one-sentence definition, the Turkish term, the source in code, and a link to the page that explains the term. Use it to look up a word; follow the link for the explanation.

Scope and source¶

  • Defined in: the "Terms introduced" tables of every page under docs/wiki/, except the documentation standard and the build folders.
  • Count: 491 terms. They were harvested from 508 table rows on 172 pages; terms that differ only in letter case or code font were merged.
  • Shared terms: 16 terms are introduced on more than one page. Each has one definition that fits every introducing page, the same definition appears in the "Terms introduced" table of each of those pages, and every introducing page is linked in the last column. The code identifier and source columns name the identifier of the first page in path order.
  • Order: rows are sorted alphabetically by the English term, ignoring code font and leading punctuation. The Turkish twin keeps the same order, so both pages match row for row.
  • Each definition and source comes from the page that introduces the term.
